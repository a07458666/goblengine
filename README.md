# 🧠 Goblengine

**A mischievously smart AI engine for crafting TRPG characters, quests, and storylines.**

Goblengine is a modular, agent-powered TRPG assistant built on MCP (Model Context Protocol). From lone goblin rogues to multi-arc revenge plots, Goblengine turns your prompts into fully playable content — character sheets, backstories, NPCs, and dynamic questlines.

Whether you're a Game Master preparing for tonight’s session, or a solo worldbuilder looking for inspiration, Goblengine has your back (and maybe a hidden dagger too).

🧰 Features:
- AI-generated character sheets in JSON (D&D 5e style)
- Dynamic backstory & personality generation
- Procedural quest arcs & branching scenarios
- Auto dice rolling (1d20, 2d6, etc.)
- Modular Tool design via MCP

Coming soon: battle simulation, loot generation, and web UI.
